# Javis Neon Pilot skin

The first visual source is based on the CC0 `Anime Girl` sprite published by Hordana on OpenGameArt:

- Source page: https://opengameart.org/content/anime-girl
- Source file: https://opengameart.org/sites/default/files/11walk_4.png
- License: CC0, as stated on the source page

`idle.png` is the first frame cropped from the transparent `11walk_4.png` strip for the Javis first-version skin runtime. The original strip is kept as `walk-source.png` for later hatch-pet v2 atlas assembly.
