# Javis 源码区与测试区规则

更新时间：2026-08-12

## 目录职责

| 路径 | 职责 | 规则 |
|---|---|---|
| `G:\Javis` | 主源码、依赖、缓存、编译和集成区 | 当前唯一可信源码区。修复完成后在这里运行测试与构建验证。 |
| `G:\Javis-worktrees` | 历史隔离开发现场 | 仅用于读取、比对和迁移未完成修复；新任务不再默认继续写旧 worktree。 |
| `G:\Javis\.codex\worktrees` | 后续 Codex 隔离开发区 | 需要隔离分支时优先放在当前项目内部，保证 Codex 可写根仍在 G 盘。 |
| `G:\Javis\tmp` | 临时文件、测试夹具和工具缓存 | 测试命令必须显式设置 `TEMP`、`TMP` 到这里，避免临时源码夹具落到 C 盘。 |
| `D:\Javis` | 真实用户测试端 | 只用于安装后体验、升级、卸载和真实用户路径验收；不作为源码、依赖或构建缓存。 |
| C 盘用户目录 | 系统和应用默认用户区 | 开发阶段不主动写 Javis 源码、构建物、缓存或测试数据。只有真实安装包按产品设计运行时，才允许验证其用户数据行为。 |

## 执行规则

1. 不把 D 盘当开发区，不把 C 盘当缓存区。
2. 所有源码修改先在 G 盘完成，并配套回归测试。
3. 运行 Python、Node、Rust 验证时设置：

   ```powershell
   $env:TEMP='G:\Javis\tmp'
   $env:TMP='G:\Javis\tmp'
   ```

4. Rust 验证使用 G 盘离线工具链与缓存，不触发网络下载。
5. 运行时数据库、会话日志、录音片段和临时补丁不进入提交。
6. D 盘验收只复制或安装最终产物；本轮语音/模型/UI 修复不生成安装包。
7. Life OS 分支继续冻结在 `eeebcbd`，不混入本轮语音、模型和界面修复。

## 本轮收口标准

- 麦克风设备名不乱码。
- 诊断探测使用用户选择的设备。
- 连续监听切换设备时释放旧流并重启新流。
- 无有效声音时不误报为转录成功。
- Live/Code 模型路由刷新和保存不互相覆盖。
- 状态显示保持既有四态语义，错误恢复后能回到监听。
- 设置页返回按钮可读，快捷项布局在窄窗口下不错位。
- 只在 G 盘完成源码验证，不合成安装包。
